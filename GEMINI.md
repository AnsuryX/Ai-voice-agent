# AI Voice Agent Project Instructions

## Project Overview
This project is a high-performance, visually polished AI Voice Agent. It utilizes a Python/FastAPI backend for AI orchestration and a React/Vanilla CSS frontend for a modern user experience.

## Tech Stack
- **Backend:** Python (FastAPI), Pydantic, OpenAI API (GPT-4o, Whisper, TTS).
- **Frontend:** React (Vite, TypeScript), Vanilla CSS for custom styling.
- **Communication:** WebSockets for real-time interaction.

## Architectural Standards
- **Clean Architecture:** Separate concerns between API routes, service logic (AI interaction), and external integrations.
- **Async First:** Use asynchronous patterns for all I/O bound operations, especially AI API calls.
- **Type Safety:** Strict typing in both Python (type hints) and TypeScript.
- **Visuals:** Prioritize a "premium" feel with smooth transitions, interactive animations (e.g., voice waveforms), and responsive design.

## Development Workflow
1. **Research -> Strategy -> Execution.**
2. **Empirical Validation:** Always verify AI responses and audio streaming logic.
3. **Surgical Edits:** Keep changes focused and well-documented.
